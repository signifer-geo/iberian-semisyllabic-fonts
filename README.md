# Iberian Semisyllabic Fonts & IME

An open-source project providing TrueType/OpenType fonts and an Input Method Engine (IME) for the Paleohispanic Western and Eastern Iberian Semisyllabic scripts on Debian 12.

## Requirements
* Debian 12 (Bookworm)
* FontForge (`sudo apt install fontforge python3-fontforge`)
* Fcitx5 (`sudo apt install fcitx5 fcitx5-table libime-bin`)
